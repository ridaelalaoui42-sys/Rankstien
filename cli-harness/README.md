# cli-anything-rankstein

Agent-native CLI for **RankStein** — Enterprise AI SEO Platform.

Generated by [CLI-Anything](https://github.com/HKUDS/CLI-Anything) methodology.

## What This Does

Wraps RankStein's entire SEO API into a structured, agent-controllable CLI with:
- `--json` output mode for AI agent consumption
- SSE streaming for live pipeline monitoring
- Full CRUD for domains, campaigns, integrations
- All SEO tools accessible from terminal

## Install
```bash
cd cli-harness
pip install -e .
cli-rankstein --help
```

## Quick Start
```bash
# Set API credentials
export RANKSTEIN_API_URL="http://127.0.0.1:8080"
export RANKSTEIN_API_KEY="your-secret"

# Launch a full SEO campaign
cli-rankstein campaigns launch \
  --keyword "best ai seo tools 2026" \
  --domain "techblog.com" \
  --niche "Technology" \
  --json
```

## For AI Agents

All commands support `--json` flag. Example agent workflow:
```
1. cli-rankstein domains add --name myblog --url https://myblog.com --niche Tech --json
2. cli-rankstein seo keywords --seed "ai tools" --json
3. cli-rankstein campaigns launch --keyword "best ai tools" --domain myblog.com --json
4. Monitor SSE stream for pipeline progress
5. cli-rankstein campaigns approve --id <campaign_id> --json
```

# Current CLI Note - 2026-05-10

This harness is the API-facing `cli-rankstein` package. The canonical local project CLI is the root command `python rankstein.py`. Subscriber administration lives only in the root CLI:

```bash
python rankstein.py subscribers add user@example.com --source cli
python rankstein.py subscribers list
python rankstein.py subscribers unsubscribe user@example.com
python rankstein.py subscribers export subscribers.csv
```

Use this harness for API health, campaign, SEO, integration, analytics, and credit workflows.
